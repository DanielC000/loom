# 19074e42 — board multi-select reads the one focus position, and a selection is only ever rendered cards

Spec: `packages/web/e2e/board-multi-select.spec.ts`, on `/overview` and `/board`. Builds on `docs/decisions/591fe6ed-board-keyboard-navigation.md`; shortcut inventory: `docs/decisions/a1c6e339-atlas-keyboard-shortcuts.md` §1.

## The model

- **The selection is a set of card ids in `Board`, handed down on the same `BoardNavContext` as the focus position.** There is no second cursor: the range anchor for Shift-click is `BoardFocus`'s item at the moment of the click.
- **A selection press does not move focus before it is read.** The card's open target suppresses `mousedown` when Ctrl/⌘ or Shift is held (which also stops Shift from painting a text selection), so `focusPos` is still the previously focused card when the click arrives. The press then focuses the clicked card itself, so it becomes the next anchor. A plain press is untouched and opens the card.
- **A range is one lane's rendered cards between the anchor and the target.** An anchor in another lane, on a header or on "Show N more" yields no range, and the click selects just the clicked card.
- **Keys:** `x` toggles the focused card; Shift+↑/↓ adds the focused card and its neighbour in the same lane and moves focus there; Escape clears. `x` and Shift+↑/↓ are read only by the lane grid's own `onKeyDown`, so they can only fire while a board item holds focus, never from a field. `x` was free (`n` was the app's only bare-letter key) and is the common "select row" key in list UIs; Shift+arrow is the platform idiom for extending a selection and the grid ignored Shift before. Space was not used because it already opens a card, like Enter. Escape is a `window` listener, live only while the selection is non-empty, and it uses `shortcutBlocked` (the same rule as `n`), so a dialog, a menu or a field keeps its own Escape. The bulk bar's own controls are the one exception (they act on the selection, and a focused `<select>` would otherwise swallow the key); clearing from the bar returns focus to the board's Tab stop, since the control that held it unmounts.
- **The selection is a subset of the rendered cards, always.** After every board and lane render, `pruneSelection` drops any id the grid no longer renders: a filter hid it, its lane collapsed, the done cap or window dropped it, or the poll found it deleted. A card that only changed lane is still rendered, so it stays selected. Un-hiding a card does not bring it back.
- **Bulk actions are one `api.updateTask` per card,** settled together with `Promise.allSettled`. A card already in the target state is skipped and counted as such. Cards that failed are listed with the server's reason in a `role="alert"` line and become the whole selection, so a retry is one action. A fully successful action keeps the selection, so a second action can follow (move, then set the priority). The board and each touched card's detail query are invalidated afterwards.

## Do not

- **Do not add a second anchor or cursor for selection.** Read `BoardFocus`; if the anchor is wrong, the fix is in how focus moves, not a parallel position (591fe6ed's own rule).
- **Do not let Space toggle selection.** Space opens a card today, exactly as Enter does, and the card requires a plain click/Enter to keep opening it.
- **Do not report an action as done for a card whose request failed, and do not drop a failed card from the selection.** The failure list and the narrowed selection are the user's only way to see and retry what did not happen.
- **Do not keep a selected id the grid no longer renders.** An action on a card the user cannot see is an action they did not intend.
- **Do not route bulk actions through a new endpoint or a batched write.** One PATCH per card keeps the server's per-card refusals per card, which is what makes a partial failure reportable at all.
- **Do not put `aria-pressed` on a card for its selected state.** Its activation opens the card, not the selection; the state is carried by `data-selected`, the fill and edge, and a visually-hidden "(selected)".
